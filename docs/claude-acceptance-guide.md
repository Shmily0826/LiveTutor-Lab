# 第二次集中验收说明 v2（定向复测约20分钟）

**目前建议做定向复测，完整验收仍为 PARTIAL。** 源码两句讲解、特定停顿追问、重启接续已取得新证据；自然答错的语音评分路由和角色自主高亮仍有失败。完整结果见 [第二轮状态](codex-overnight-status.md) 与 [彩排报告](evidence/codex-r2-p8-rehearsal-2026-10-16.md)。固定WAV接收音频、软件播放状态、真实可听性、真人体验分别判定。

## 开始前

1. 你本人准备验收时告诉协助者“准备好了”，再把 benchmarks/raw/daily-companion-audio-policy.json 的 audio_allowed 改为 true。本轮无人值守始终保持 false，没有开麦；授权Goal开发不等于已经开始真人验收。
2. 关闭其它占用48911/48916的开发实例。扬声器由你设置；检查麦克风输入音量和距离，确保正常说话能被识别。第一次验收首句峰值约270，低于当时500阈值；无人值守阶段没有替你改系统音量。
3. 双击 Start-Daily-Tutor-Voice.cmd，等待角色和Study显示就绪，再点角色麦克风。默认停顿参数为KEEP=100ms、HOLD=1500ms；特定固定WAV连续两场与彩排得到单条识别，不能保证所有真人句子都不拆分。
4. 在 **Study窗口**的“课程ID”输入新ID，例如 sky-scout-acceptance-v2-20261016，点“选择 / 返回课程（接续原题）”，确认当前课程。不要清理旧课程。“新开Session”会退役当前题，第5步后不要误点。
5. 点“选择学习图片”或粘贴自己的Sky Scout架构图PNG/JPEG，核对预览后点“Explain／讲解”，等讲解返回。仅选文件还没有提交。确认不是遗留的WEX/NUD/REZ测试图。

| # | 你做什么 | 应检查什么 |
|---|---|---|
| 1 | 等启动完成 | 终端、角色、Study都就绪，当前课程正确；记录失败提示。 |
| 2 | “讲一下weather_service.dart里非200响应怎么处理，两句话。” | 先查实际源码；说明22–24行抛异常，26行解析不执行。记录首声等待与行号读法。这版没有补做“正在查看源码……”状态提示，不能把它当已交付。 |
| 3 | 它说话时插入“等一下，先说结论。” | 旧声是否真的停下、新回答是否切题。固定WAV有软件取消/新音频证据，但本轮一次新答偏成文件位置，仍需照实记录。 |
| 4 | 带自然停顿说“那如果……把这个判断改成只在500以上才抛……404会怎样？” | 一轮接上刚才源码，404绕过throw继续到26行；解析是否成功应取决于实际响应体，不能当确定事实。记录空回合、拆句、范围拒绝。 |
| 5 | “给我出一道题。”答错，再说“刚才说错了，应该是……” | 为明确正在作答，可以先说“我的答案是……”。必须在Study核对错答和纠正两条记录、同题新尝试与成绩；角色说“记住了”不算。无作答标记的否定陈述在本轮两场被当材料纠错，未评分；明确措辞也不保证通过。 |
| 6 | 在 **Study**换一张图并点Explain提交，再问“这张图里谁调用谁？”并让角色指示关系 | 回答是否使用新图，换图时旧声是否停。自主高亮本轮三场未通过；角色说“标好了”也可能没有命令，以实际高亮为准。材料窗口里换HTML/PNG不会替换Study提交图。 |
| 7 | 关程序后重启，问“我们上次讲到哪了？”，再问“那段代码404会怎样？” | 应复述课程、源码文件/范围、最近题目与实际成绩、下一步；追问应重新读源码。已有成功的SDK/Native复核，仍记录现场遗漏、空回合与不准确行号。 |

## 本版已知限制

- **评分存储与语音意图分开。** 直接真实SDK错答0→纠正100并保留历史通过；此前明确作答的Native链也有成功证据。本轮自然否定陈述却未调用评分，唯一提示措辞复核无效且已撤回。不能宣布所有语音答错都会落库；需要复核待答题与ASR意图衔接，没有启用实验自动评分。
- **自主指示未通过。** PNG无可靠区域定位时不应猜坐标；HTML对照也没有accepted高亮。一次角色还无依据地说“标出来了”。手动窗口测试或SDK成功不替代角色自主指示。
- **插话的机械停止和语义分别验。** 软件取消旧队列、收到新音频不等于真人听到停止，更不等于新回答正确切题。
- **讲解仍可能给错语句行号或过强推断。** 本轮一次把throw说成22行，实际在23行；源文件范围/实际语句应现场核对。数字和英文标识符的听感待用户。
- **不承诺固定响应秒数。** 真人原场的9秒区间还不能定位到provider、网络或本地接收；本轮观察没有发现约2KB工具结果明显膨胀，也没有做性能压缩A/B或修改仲裁/传输。
- **重启摘要只读现有课程记录。** 没有新建记忆系统，不推断没保存的成绩；空课程应诚实说明无可接续记录。工具读取摘要本身不调用教师，角色说话仍使用角色模型。
- 指示仅限受控材料窗口，不支持任意桌面窗口。本轮未新增宿主状态提示、自动补发、实验自动评分或声学验收。

## 验收后

把每步是否通过、首声等待、是否听到旧声残留与成绩记录告诉协助者；结束后把audio_allowed改回false。不要为了复测删除旧课程或学习历史。
