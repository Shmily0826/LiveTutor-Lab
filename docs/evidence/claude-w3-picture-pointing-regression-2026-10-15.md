# W3：图片与指示回归

日期 2026-10-15。证据层级：浏览器 DOM（真实只读 Study SDK，零模型）+ output-only Native 固定 WAV（扬声器为用户预设 4%，无麦克风、采集、回环）。可听性与真人待用户。复用已有对比图 `diagram-input-forward.png` / `diagram-input-reverse.png`，没有生成新图。

## A. 学习材料窗口：指示 → 换图 → 旧状态不回放（`claude-w3-material-flow-1`，账本 +0）

`scripts/neko_material_flow_probe.py` 原样重跑：完整 Study 入口 bootstrap + 10 次只读 SDK 调用，两个视口（390×844、1440×900）共 40 项 DOM 检查全部通过：

- HTML 模块指示在学习者滚动后对齐（误差 < 2 px），指示不改材料节点；
- HTML 换到图片后旧指示消失；图片点击、1.5 倍缩放、滚动后指示仍对齐；
- 换成 reverse 图后旧指示消失，把更早的 state 回放给客户端也不会恢复旧材料或旧箭头；
- 清除键生效；关闭材料窗口再打开，保留选中的 reverse 图、没有旧指示、能重新指示。

范围：DOM 驱动的点击，不是可信的物理点击；不测任意桌面窗口；不是角色自主选择指示工具。原学习历史逐行 SHA 与 4 个材料文件 SHA 前后不变。

## B. 角色语音：讲图 → 换图 → 用新图（`claude-w3-voice-replacement-1/2`，`NEKO_PAUSE_HOLD=1`）

两场都是同一连接两段固定 WAV，第一段播放中把 Study 图片换成 reverse 图（REZ → NUD → WEX，箭头朝左），第二段问"刚换的图上三个模块的连接方向"。

| 场 | 第一段 | 结果 |
|---|---|---|
| `…replacement-1` | 沿用 2026-10-14 的英文夹具 | 夹具被拆成两条识别，角色把"weather request path"理解成源码题并调 `study_explain(project_code)`，该 store 没有授权项目，说了"请指定一至三个有界源码范围后再讲解"（0.34 s 就播完）。换图时旧语音几乎已结束，所以严格的"旧令牌取消/停止回执"检查没有可检验的对象（FAIL_OR_PARTIAL）。第二段**正确**：箭头都朝左，REZ → NUD → WEX。账本 DeepSeek +20、app +2 |
| `…replacement-2`（新中文夹具，约 8.6 s，"请仔细讲一下当前这张图，每一条箭头的方向都说一说"） | 角色用 `study_explain` 开始讲当前图 | **9 项候选检查全部通过**：旧原生令牌的取消回执收到、原生队列停止回执收到、第二段使用新原生令牌、每段都有 PCM、每段无提前 provider 音频、偏好仍是中文、会话正常。第二段回答"图上三个模块的箭头都向左：REZ 指向 NUD，NUD 指向 WEX"，与 reverse 图一致。账本 DeepSeek +16、app +2 |

- 第一场的失败是夹具问题，不是换图机制问题：英文夹具在新工具说明下会被理解成源码题。第二场换成中文夹具后机制通过；两场各只做一次，没有重试同一个场。
- 第二场第一段仍出现两条识别事件（"请仔细讲一下当前这张图"与"每一条箭头…"），宿主日志里暂扣生效（"暂扣丢弃 0.09 s / 0.37 s 停顿"），但 provider 在约 0.3 s 的 TTS 逗号停顿处就分段出了识别；**工具调用发生在第二条识别之后**，只回答了一轮。这与场 51 里"第二半句识别在回答开始之后才到"不同，但说明提供商端的分段在较短停顿（< 0.4 s）处仍会发生，暂扣只保证长停顿。
- 严格检查标注为 `CANDIDATE_CHECKS_PASS_REQUIRES_SEMANTIC_REVIEW`；语义我已对照图片复核。
