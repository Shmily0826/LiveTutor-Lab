# 日常学习伙伴：启动与集中体验

用户最新指令允许必要时使用其设定约4%的扬声器，仍禁止麦克风。Main不调整系统音量；固定WAV以内存/WS发送，不初始化真实或虚拟捕获设备，不使用回环。新的source/Native/probe输出专用路径先安装捕获API拒绝保护，再加载应用；普通混合语音入口仍被本任务audio policy拒绝。下述普通日常启动和真人步骤不因扬声器授权而自动获得麦克风许可，真人麦克风等明确“准备好了”。最新证据见 output-only 报告，Native PCM/播放状态与物理声音、真人听感分层记录。

阶段九支持图片重查的明确来源与同材料auto纠正；拒图、来源不明、材料替换和排队来源过期时明确拒绝。默认关闭的自然停顿实验已接真实Core/Omni并通过离线，provider分片和设备/真人未验。阶段十在保存英文解释前校验中文讲解/图标签，最多一次同模型局部翻译，失败诚实说明；已有代码/数据原文保持，不能确定的代码拒绝翻译。新的recheck24真实图片/SDK/DB两句English纠正通过，旧22/23夹7汉字FAIL仍保留；不外推所有英语、语音或真人通过。最新范围见 `docs/evidence/daily-companion-english-reply-guard-2026-10-14.md`。

在本机双击项目根目录 `Start-Daily-Tutor.cmd`。使用现有已安装的隔离 N.E.K.O 运行环境，打开原生角色、Study 图片面板和只读学习材料窗口。不要在此版本重新搭建 CodeGraph 或拷贝旧数据库。当前阶段 Goal 仍 active，下面是可用流程与待验收步骤，不代表全部完成。

入口现在默认**文字模式**：角色与聊天页面加载前拒绝捕获API，窗口静音，使用聊天输入框。原生 `text-only-userdata` 与浏览器 `browser/text-profile` 随同一个daily store持久保存。现有学习数据库不清空、不另拷；阶段十五在独立task store实际启动/同profile重启、输入框及保护安装通过，阶段22原daily文字入口、Ready/refresh、当前图片与既有待答题/历史/设置保留已实际验证。语音另入口 `Start-Daily-Tutor-Voice.cmd` 仍受麦克风许可限制，目前不要使用。扬声器约4%许可仅用于必要的输出专用验证，不等于麦克风授权。

阶段22–23：学习材料窗口默认跟随当前课程实际提交的Study图片，换图/换课会更新并使旧指示失效；参考HTML及源码仍由你选择。日常退出恢复本次文字/语音临时provider选择，保留其它设置；异常退出恢复不保证。正式错答更正保留原题，以新attempt记录后续评分；已评分题和最近反馈可在换课返回、重启及空闲续接后读回，明确重新开始仍是新会话。最新证据见阶段23报告。

Native语音直接作口头判断仍可能绕过正式评分，这项在继续修；口头评价不能当已保存成绩。现在自动验证核心，不要求你继续配合逐句测试。最终语音转述和真人集中验收完成前，支持范围按报告分层，不声称全部日常闭环已完成。

日常设置、课程、题目及明确提交的图片保存在 `benchmarks/raw/neko-daily-companion`，浏览器 profile 也跟随该 store。第一次图片学习给课程填一个固定 ID，例如 `sky-scout`，点击开始 Session；以后同课程继续使用同一 ID。选择或粘贴图片，再点击讲解，随后向角色追问“再讲简单一点”“给我一题”“我刚才错在哪里”。读窗表单默认收起；需要时展开并核对精确窗口标题和内容标记，首版 OCR 读窗只返回文字。

源码问答已授权用户指定的 Sky Scout，只读既有索引与源文件。例如“查询 fetchWeather，解释天气请求如何发出”。工具返回的过滤源码会加入学习材料菜单；学习者选择它、滚动到要看的行，再让伙伴指向当前展示的行。工具引用会注明源码版本与实际展示范围；未展示的调用点不能冒称已读。

长期偏好可明确说“以后这门课用英文”“以后讲短一点、先举例，不主动出题”。单次“这次用英文、两句话”仅影响当次教学。明确偏好复用既有 SQLite kv，不创建第二套记忆数据库。重启及换课返回的材料/学习记录已有真实 API/DB 证据。

启动报错查看 `benchmarks/raw/neko-daily-companion/launcher.log`；运行报错查看 `benchmarks/raw/neko-desktop-host.log`。Study 断网/未就绪时保留当前图片，恢复后点击刷新，再主动提交；不会无限重试模型。Enter 或 Ctrl+C 结束本次窗口与宿主。不要关闭其他 Chrome 或运行全局进程清理。

## 一次 10–20 分钟真人体验

新增材料替换保护已有固定输入设备证据：当前Study图核对使用最新图片；换图时精准停止旧Native队列，并可用新输入在新连接讲新图（replacement14）。明确源码text保持独立。quiz/grade/summary来源保护已有voice17三轮工具、数据库、Native和完整设备回环证据；独立叙述仍默认关闭、宿主保护未完成。新连接首次输入前长时间静默曾约20秒断开（replacement13），代理读取deadline现已修复，gen2首次长静默仍待精确验证；遇到停止状态请重新开始语音。密集小字/真人听感仍待验，submitted仅通知提交。

阶段七与八最新证据：voice17连续出题、错答评分、总结均真实调用工具并实际播放，同题同attempt只记一次评分。首PCM分别在输入结束后约8.043、6.103、6.592秒。反馈空间方向表述不够直接、总结曾漏下一步并把材料请求误当完成讲解，这些失败保留。阶段八已修角色投影和总结规则；quality19真实后端重启接续能明确引用此前错答、REZ→NUD→WEX与具体下一步，旧记录不改。它是Study/SQLite/model证据，没有新版总结的Native/设备/真人证据。最多三条已有评分记录的总结锚点在阶段十三C31已真实SDK/model/SQLite限定通过：8条中性离线教师窗口夹具挤出旧错答后，模型仍准确引用更早英文wrong0与既有下一步，未混较晚10分；不是自然连续真人/新声音证明。阶段十四还发现并修复换课返回原待答题丢失，按课checkpoint和public status目前源码/离线过，实际角色接续待验；显式新开会话仍fresh。遇到没有听到题目，请先在Study查看当前题，不把未朗读题当完成教学。

仅在用户明确说“准备好了”后安排，不要求夜间朗读，不采房间麦克风，不自行提高系统音量。

1. 约2分钟：双击日常入口，确认三个窗口、固定课程、图片按钮；选已有 Sky Scout 图，要求两句话，追问一次。
2. 约3分钟：换到已有正向/反向对比图，让伙伴解释箭头，指出一次错误并观察它是否重查；看不清的小字应明确承认。
3. 约3分钟：中文解释→单次英文→下一次恢复课程语言；一次自然停顿的长句；在讲话中普通打断一次。评价术语、数字、标识符口语和首音频等待。
4. 约3分钟：出一题、给一个错误答案、听纠错；换课再回来，询问题目和错误；结束并重启日常入口，询问续学。
5. 约3分钟：查询 fetchWeather 的真实源码，选择返回的源码材料，滚动后让伙伴指向解释行；比较架构图里的关系。学习者操作，伙伴只指示。
6. 约1分钟：记录可日常用/仍妨碍使用的具体点，统一一次反馈；未实际做的项保持待验收。
